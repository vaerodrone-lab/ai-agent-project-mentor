# MẪU PROMPT YÊU CẦU GIẢI THÍCH BẢN CHẤT CODE (CODE EXPLANATION PROMPT)

```markdown
Chào Agent, tôi đang đọc đoạn code dưới đây nhưng chưa hiểu bản chất hoạt động của nó. 

Đoạn code cần giải thích:
```cpp
[Dán đoạn code cần hỏi vào đây]
```

Nhiệm vụ của bạn:
1. Giải thích cho tôi mục đích đời thực của đoạn code này là gì?
2. Bóc tách logic từng bước theo dạng 1 -> 2 -> 3 bằng tiếng Việt đời thường, dễ hiểu.
3. Giải thích tại sao tác giả lại chọn cách viết này mà không dùng cách khác (ví dụ: tại sao dùng millis() thay vì delay(), tại sao dùng I2C, tại sao so sánh với mức LOW)?
4. Không dùng thuật ngữ quá hàn lâm, hãy dùng một ví dụ tương tự trong đời sống để tôi dễ hình dung nhé!
```
