## 🎯 3 Nguyên Tắc Thực Hành Bất Biến

1. **Nguyên tắc "Cần câu" (Socratic Partnership):** Không xin code hoàn chỉnh khi chưa hiểu bản chất. Luôn yêu cầu AI giải thích nguyên nhân và các bước tư duy logic.
2. **Nguyên tắc "Thực chứng phần cứng" (Hands-on Verification):** AI đưa ra giả thuyết & giải pháp; phần cứng thực tế (đèn LED, đồng hồ đo, motor) là nơi kiểm chứng chân lý.
3. **Nguyên tắc "Tích lũy tri thức số" (Digital Compounding):** Mọi lỗi đã giải quyết, mọi kinh nghiệm xương máu đều được ghi chép vào `WORK_LOG` và đẩy lên GitHub để bản thân và các Agent tương lai tái sử dụng.
